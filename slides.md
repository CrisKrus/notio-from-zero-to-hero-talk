# Nivel 1 · Bloques

- Texto, listas, títulos, callouts, imágenes, archivos, vídeos, código, embebidos…
- Escribe `/` para buscar un bloque.
- Puedes **mover, duplicar, convertir y anidar** bloques.
- No memorices el catálogo: aprende a explorarlo.

# Superpoderes del teclado

| Escribe | Hace |
|---|---|
| `/` | Abre menú de bloques |
| `@` | Menciona una página, persona o fecha |
| `[[` | Busca o crea un enlace a página |
| `#` + espacio | Encabezado |
| `[]` + espacio | Casilla de verificación |

| Atajo | Hace |
|---|---|
| `Cmd/Ctrl + P` | Buscar o saltar de página |
| `Cmd/Ctrl + D` | Duplicar bloque |
| `Cmd/Ctrl + F` | Buscar en página |

# Nivel 2 · Páginas

- Una página organiza **bloques y subpáginas**.
- Barra lateral, enlaces, menciones y favoritos facilitan navegar.
- Enlazar una página **no es duplicarla**.
- Organiza lo justo: evita crear una estructura inmensa desde el primer día.

# Nivel 4 · Conecta la información

**Proyectos** ↔ **Tareas**

- **Relación:** asocia registros de bases diferentes.
- **Rollup:** resume datos de registros relacionados.
- **Vista vinculada:** muestra una base existente en otro lugar.
- **Plantilla:** predefine bloques y propiedades al crear registros.

> ¡Conectar información no es copiarla!
