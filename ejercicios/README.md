# 🧠 Ejercicios

> 🚀 **Notion: From Zero to Hero** · Material de práctica para después de una charla de 45 minutos + 15 minutos de preguntas. Puedes empezar desde cero o saltar al reto que encaje con tu nivel.

> Esta es una copia estática del material de Notion, adaptada a Markdown para consultarla desde GitHub sin acceso al workspace. Los cambios posteriores en Notion no se sincronizan automáticamente.

## Cómo utilizar estos ejercicios

1. Crea tu propio espacio de pruebas en Notion; **no edites los enunciados**.
2. Realiza los retos en orden: cada uno reutiliza lo aprendido en el anterior.
3. Consulta las pistas solo cuando te bloquees.
4. Antes de abrir la solución orientativa, comprueba los criterios de éxito.
5. Usa ejemplos ficticios; evita datos confidenciales.

## Chuleta de atajos

| Acción | Atajo |
| --- | --- |
| Insertar un bloque | `/` |
| Mencionar página, persona o fecha | `@` |
| Enlazar/crear una página | `[[` |
| Buscar o saltar de página | `Cmd/Ctrl + P` |
| Duplicar bloque | `Cmd/Ctrl + D` |
| Menú para modificar bloque | `Cmd/Ctrl + /` |
| Buscar en página | `Cmd/Ctrl + F` |
| Anidar / desanidar | `Tab` / `Shift + Tab` |
| Encabezado | `#`  • espacio |
| Checkbox | `[]`  • espacio |
